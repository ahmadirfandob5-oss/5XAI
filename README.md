# 5XAI v4

Unified 5XAI build with:
- chat and conversation memory
- migration of older local chat-history keys
- new chat / restore / delete / export
- image capture and image upload
- file attachments
- optional web search
- microphone input with browser speech recognition and MediaRecorder fallback
- server transcription fallback
- AI voice replies
- working settings overlay
- model and chat settings
- Vercel-ready Express server

Do not include `.env` in GitHub.
